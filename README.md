# Portfolio — Nick Mathieu Rakotomanana

Portfolio statique responsive construit en HTML, CSS et JavaScript vanilla.

## Lancer localement

Option simple : ouvrir `index.html` dans un navigateur.

Option recommandée :

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Personnalisation

- Contenu : `index.html`
- Design / responsive : `styles.css`
- Animations et interactions : `script.js`
- Illustrations : dossier `assets/`
- CV téléchargeable : `CV_Nick_Rakotomanana.pdf`

## Déploiement

Le projet est compatible avec GitHub Pages, GitLab Pages, Netlify, Vercel ou tout hébergement statique.
